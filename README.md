# eWASTED
Code for IRT scoring of the eWASTED PROM and shiny app


## User guide
This shiny app will calculate the IRT score for the *Warwick Axial Spondyloarthritis Fatigue and Energy* (WASTEd) questionnaire

Upload an .csv file where all individual item scores are reported. The app assumes that Columns A to are the items, whilst each new row represents a different respondent.

You can make a .csv file in Excel using the "save as" options
